# Code map: tooling

Repo tooling: tools/, .claude/ (agents, hooks, skills, wavework config), root package.json.

- tools/code-map/check.mjs: code map checker (Node built-ins only): entry format, description length, no bead IDs, paths exist, index links, no duplicate paths
- tools/code-map/test/check.test.mjs: node:test cases with temp-dir fixtures, one passing and one failing case per rule
- package.json, package-lock.json: root dev tooling only (not a workspace, `frontend/` stays on pnpm); devDependency `wavework` pinned exactly
- .claude/wavework.json: wavework config (base branch, worktree and branch patterns, per-area checks, model rules, code map, findings epics); hand-edited source of truth
- .claude/wavework.lock.json, .claude/wavework/dashboard/: wavework lock (versions, hashes, hook entries) and installed pipeline dashboard; generated, do not edit
- .claude/agents/implementer-{sonnet,haiku}.md, .claude/scripts/{red-green-check.sh,red-green-check.test.sh}: generated by wavework: implementer subagents, red-before-green check and its test
- .claude/skills/{next-task,next-task-batch,next-task-beads,next-task-branch,next-task-code,next-task-deps,next-task-e2e,next-task-findings,next-task-finish}/SKILL.md: generated by wavework: epic and bead orchestration skills
- .claude/skills/{next-task-implement,next-task-plan,next-task-review,next-task-test,next-task-write-tests,text-to-task,watch-ci}/SKILL.md: generated by wavework: implement, plan, review, test, planning and CI watch skills
- .claude/skills/apple-design/SKILL.md: design and motion guidelines every frontend UI change follows
- .claude/settings.json: Shipir permissions, `bd prime` SessionStart hook, db-write-guard PreToolUse hook, attribution off, and the dashboard hooks owned by wavework
- .claude/hooks/db-write-guard.py: PreToolUse hook that forces a permission prompt for suspected database writes
- .agents/skills/beads/SKILL.md, .agents/skills/beads/agents/openai.yaml, .codex/{config.toml,hooks.json}, .cursor/hooks.json, .cursor/rules/beads.mdc: beads integration files for Codex and Cursor
